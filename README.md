# Calculadora de descontos

Exemplo de testes unitários em .NET com xUnit.

## `[Fact]` e `[Theory]`

- `[Fact]` executa um teste com um cenário específico.
- `[Theory]` executa o mesmo teste com vários conjuntos de dados, como os definidos por `[InlineData]`.

## Executar os testes

Com o [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) instalado, rode na raiz do repositório:

```powershell
dotnet test
```
